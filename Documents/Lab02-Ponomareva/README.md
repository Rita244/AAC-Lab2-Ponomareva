1. Почему для денег используют decimal, а не double?
double хранит числа в двоичном формате и дает погрешности (например, 0.1 + 0.2 = 0.30000000000000004). decimal хранит числа в десятичном формате, поэтому расчеты точные, что критично для финансов.

2. Что произойдет при переполнении целочисленного типа?
Значение «завернется» по кругу. Например, если прибавить 1 к максимальному byte (255), получится 0. Это называется переполнением (overflow).

3. Чем var отличается от динамической типизации в Python?
В C# var — это статическая типизация. Компилятор определяет тип переменной один раз при компиляции на основе присвоенного значения, и потом его нельзя изменить. В Python тип может меняться во время выполнения.

4. Какой тип данных всегда возвращает Console.ReadLine()?
Всегда возвращает string (строку), независимо от того, что ввел пользователь.

5. Чем int.Parse отличается от int.TryParse при некорректном вводе?
int.Parse при ошибке «роняет» программу с исключением FormatException. int.TryParse не падает, а просто возвращает false.

6. Что означает false из int.TryParse, и что попадет в out-переменную?
false означает, что преобразование не удалось (введены не цифры). В переменную, переданную через out, попадет значение по умолчанию для этого типа — для int это 0.

7. Пример, когда стоит использовать TryParse, а не Parse.
Когда данные вводит пользователь вручную ( возраст или   количество книг). Пользователь может случайно ввести букву, и TryParse позволит программе вежливо попросить ввести число заново, а не «упасть» с ошибкой.
